# 💎 Image Animation Jewellery

**Image Animation Jewellery** is a creative web project that showcases jewellery using **frame-based image animations**.  
Instead of traditional videos or GIFs, this project converts video sequences into **multiple image frames** and renders them dynamically to create smooth animations.

This technique makes the jewellery display **more interactive, lightweight, and visually attractive** while maintaining high image quality.

---

## 🌐 Project Idea

The main goal of this project is to create a **modern jewellery showcase experience** using frame-based animation.

A jewellery video is converted into **hundreds of sequential image frames**, and these frames are rendered in the browser to simulate motion and product animation.

This approach allows:

- Smooth product animations
- High-quality visuals
- Better performance compared to videos
- Creative UI presentation

---

## 🧑‍💻 Tech Stack

### Frontend
- Next.js
- JavaScript / TypeScript

### Animation Technique
- Frame-by-frame image animation
- Video converted into image frames
